# WASEEM MEDICAL PRO

نظام وسيم الطبي PRO لإدارة المراكز والعيادات الطبية والمرضى والمواعيد والجلسات والباقات والفواتير والإشعارات والتقارير.

## المرحلة الأولى
- تطبيق Flutter Android بواجهة عربية RTL.
- تسجيل الدخول.
- لوحة تحكم.
- المرضى.
- المواعيد.
- الباقات والجلسات.
- الفواتير.
- مركز الإشعارات.
- التقارير.
- الإعدادات.

## البنية
- mobile: تطبيق Flutter.
- backend: واجهة Laravel REST API لاحقاً.
- admin-panel: لوحة الإدارة لاحقاً.
- database: مخططات PostgreSQL.
- .github/workflows: بناء APK تلقائياً.

## تشغيل التطبيق
داخل مجلد mobile:
```bash
flutter pub get
flutter run
```
